# Сайт ReClash

*[English](README.md)*

Сайт клиента [ReClash](https://github.com/Hoxiee/ReClash) на mihomo: лендинг,
интерактивный справочник и конструктор HTTP-заголовков для провайдеров, загрузки,
быстрый старт, галерея, мок-подписки и декодер отчёта подписки. Двуязычный (RU/EN),
живёт на **https://reclash.pages.dev**.

Статика по построению — ни npm, ни бандлера, ни CDN во время выполнения.
Генератор — один скрипт на Python 3 из стандартной библиотеки; всё, что
отдаётся, пересобирается в `dist/` из `gen/` и `assets/`.

```
python3 build.py            # собрать в dist/
python3 build.py --serve    # собрать и поднять http://127.0.0.1:8000
```

Тексты двуязычны прямо в исходнике — `t("текст", "text")` — поэтому пропущенный
перевод это пропущенный аргумент, а не тихая дыра. Страницы заголовков читают
один источник (`gen/spec.py`), мок-подписки — другой (`gen/mocks.py`).

## Проверки

```
python3 tools/verify.py         # структура dist/, контракты JS<->HTML, ссылки, паритет RU/EN
python3 tools/check_headers.py  # покрытие полей / идентификаторов / строк конструктора
node   tools/e2e.mjs            # Chromium: ошибки консоли, переполнения, обрезанный текст
```

## Выкладка

Cloudflare Pages, из корня `dist/`. Мок-подпискам нужны заголовки ответа
`ReClash-*` из `dist/_headers` — Pages отдаёт их как есть.
